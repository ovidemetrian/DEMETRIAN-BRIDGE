# Concept 1977 · Demetrian Bridge

A matrix of sound. Four speakers, one listener, one outcome.

**Concept & invention: Ovi Demetrian** · Romania, 1977

The Demetrian Bridge spreads a recording naturally around one listener using four real sources, without processing that changes the creator's intent. Depth comes from the phase relationship between drivers, set together with their crossovers. Realism means every sound at its true location, at the same time.
